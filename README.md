# Pokopia Arranger

Automatic MIDI arranger for Pokémon Pokopia MatMaker.

## Features

- Analyze MIDI files
- Reduce polyphony
- Compress note range
- Preserve melody
- Export MatMaker-compatible MIDI

## Installation

```bash
pip install -e .
```

## Usage

```bash
pokopia-arranger input.mid output.mid
```
